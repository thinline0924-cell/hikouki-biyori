# ひこうき日和(ひこうきびより)

いろいろな機体や車で、自然や街をのんびり遊覧するローポリ3Dゲームです。
ブラウザだけで動きます(サーバーのプログラム・APIキーは不要)。

- のりもの 8種類:プロペラ機「ひばり号」、複葉機「とんぼ号」、グライダー「かもめ号」、
  水上飛行機「うみねこ号」、小型旅客機「つばめ号」、熱気球「たんぽぽ号」、
  小さな車「こまち号」、原付「ことり号」(車と原付は地上を走って探検できる)
- コース 6つ:夕凪の群島/大瀑布の渓谷/雪嶺の峡湾/オーロラの湖/花と風車の丘/港町と時計台
  (港町には道路・建物・行きかう車・観覧車・時計台があり、車や原付で走るのにぴったり)
- どのコースにも滑走路があり、飛行機は滑走路から離陸・着陸できる(進入角を知らせる灯り PAPI、吹き流し、管制塔つき)
- 一人称視点:操縦席の計器(速度計・高度計・人工水平儀・方位計など)が動く。車はハンドル、原付はハンドルバーが見える
- エンジン音は、気筒ごとの爆発・排気管のひびき・プロペラのうなり・タービン音をその場で計算して作っている
- やりこみ:見どころのスタンプ(各コース4つ)、ひかりの粒(続けて集めるとメロディになる)、
  写真アルバム(Z キー)、ちいさな発見(12こ)
- ぶつかっても落ちません。手をはなすと機体は水平にもどります
- スマホでも遊べます(左下のスティックと右のボタン)

## 操作

| キー | 動き |
|---|---|
| ↑ ↓ / W S | 機首を上げる・下げる(気球はバーナー・弁、車と原付はアクセル・ブレーキ) |
| ← → / A D | かたむけて曲がる |
| Shift | 加速(気球はバーナー) |
| Z / X / C | 写真 / 地図 / 視点(うしろ・遠く・一人称) |
| R | スタート地点にもどる |
| マウスホイール | カメラを近づける・はなす |
| V | おまかせ飛行(自動で飛ぶ・走る) |
| B | クラクション(車・原付) |
| Esc | ひとやすみ |

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み |
| `style.css` | 見た目(クリーム色の紙と紺のインク) |
| `js/main.js` | 全体のまとめ役(メニュー、操作、カメラ、写真、スタンプ) |
| `js/courses.js` | 6つのコース(地形の形・色・空・見どころの文章) |
| `js/town.js` | 港町(道路・建物・行きかう車・海辺の小物) |
| `js/world.js` | 地形・水・空・雲・木・ひかりの粒を組み立てる |
| `js/models.js` | 機体・車・原付と小物(灯台・風車・観覧車など)のローポリ模型 |
| `js/flight.js` | 飛び方・走り方(やさしい物理)。離陸・着陸もここ |
| `js/runway.js` | 滑走路(舗装・白線・灯り・吹き流し・格納庫・PAPI) |
| `js/cockpit.js` | 一人称の操縦席(計器・窓わく・ハンドルなど)。景色の上に重ねて描く |
| `js/audio.js` | 音(風・エンジン・オルゴール風のBGM・効果音)。音のファイルは使わずその場で作る。エンジン音は AudioWorklet(音専用の処理)で1サンプルずつ計算 |
| `js/data.js` | のりものと「ちいさな発見」のデータ |
| `js/save.js` | 記録の保存(ブラウザの localStorage だけ) |

- ビルドツールは使いません。3D表示の Three.js 0.170.0 を CDN(jsdelivr)から読み込みます
- 記録と写真は、遊んだブラウザの中だけに保存されます(外へは送りません)

## 公開のしかた(Render)

1. <https://render.com> にログインし、「New +」→「Blueprint」を選びます
2. このリポジトリ(`hikouki-biyori`)をえらびます
3. `render.yaml` が自動で読み込まれるので、「Apply」を押します
4. 数分で URL が発行されます(静的サイトなので無料・APIキー不要)

> パソコンで試すだけなら、このフォルダで簡単なWebサーバーを動かして `index.html` を開きます。
> (ファイルを直接ダブルクリックすると、ブラウザの決まりで読み込めないことがあります)
